# Carbox Refinement Restraints Integration

A primary design objective of the **Carbox & CarboxMol** suite is seamless interoperability with world-standard macromolecular refinement software, notably **Carbox Refinement** and **Carbox Refinement**.

---

## 1. External Distance Restraints Syntax

When Carbox identifies an anomalous short contact ($d_{O\cdots O} \le 3.20\,\text{Å}$) or Low-Barrier Hydrogen Bond ($d \le 2.55\,\text{Å}$), it generates formal external restraint records adhering strictly to CCP4 Carbox Refinement syntax:

```text
exte dist first resi <resi_1> chain <chain_1> atom <atom_1> second resi <resi_2> chain <chain_2> atom <atom_2> value <dist> sigma <sigma>
```

### Parameter Guidelines
- **`value`**: Target inter-atomic distance in Angstroms ($\text{Å}$).
  - For standard neutral-anionic H-bonds: $2.60\,\text{Å}$.
  - For ultra-short LBHB: $2.42 - 2.48\,\text{Å}$.
- **`sigma`**: Restraint weight / standard deviation.
  - Recommended: $\sigma = 0.02\,\text{Å}$ for high-confidence crystallographic restraints ($R_{\text{cryst}} \le 1.8\,\text{Å}$).
  - Permissive: $\sigma = 0.05\,\text{Å}$ for lower resolution data ($R_{\text{cryst}} > 2.2\,\text{Å}$).

### Example Generated Restraints
```text
# Generated by Carbox (v0.4.5) - Suleiman M Hajizadeh & Garib N Murshudov
exte dist first resi 25 chain A atom OD2 second resi 102 chain A atom OE2 value 2.450 sigma 0.02
exte dist first resi 301 chain A atom ZN second resi 25 chain A atom OD1 value 2.050 sigma 0.03
```

## 2. Explicit Protonation: ASH and GLH Parameterization

In standard CCP4 monomer libraries:
- **`ASP`**: Fully deprotonated carboxylate ($\text{O}\delta_1, \text{O}\delta_2$).
- **`GLU`**: Fully deprotonated carboxylate ($\text{O}\varepsilon_1, \text{O}\varepsilon_2$).
- **`ASH`**: Neutral Aspartate with explicit hydrogen ($\text{H}\delta_2$ attached to $\text{O}\delta_2$).
- **`GLH`**: Neutral Glutamate with explicit hydrogen ($\text{H}\varepsilon_2$ attached to $\text{O}\varepsilon_2$).

Carbox can automatically re-label the proton-bearing carboxyl partner from `ASP`/`GLU` to `ASH`/`GLH` in the mmCIF coordinate stream before refinement.

---

## 3. Running with Carbox Refinement

Carbox Refinement executes crystallographic and cryo-EM refinement using Carbox Refinement with modern GEMMI coordinate handling:

```bash
# Refinement with Carbox external restraints in Carbox Refinement
carbox refine \
  --model input.cif \
  --hklin data.mtz \
  --restraints carbox_restraints.txt \
  --output refined_carbox \
  --ncycle 10
```

### Key Carbox Refinement Keywords
- `--restraints <file>`: Reads external distance and angle restraint records.
- `--keywords "RESI ..."`: Specifies custom monomer parameterization for neutral residues.
- `--hydrogen all`: Adds all hydrogen atoms explicitly according to local stereochemistry.
