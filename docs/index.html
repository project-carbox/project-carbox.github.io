1. Quick-Start CLI Commands

Run instant single-structure PDB validation, batch surveys, or REFMAC5 restraint generation from your terminal:

# Direct PDB structure inspection & contact screening
carbox 4LGN
carbox 1KZK --Format json

# Multi-PDB directory survey with CSV export
carbox survey ./pdb_dataset --cutoff 3.2 -o results.csv

# Asymmetric C-O / C-OH REFMAC5 & Servalcat restraint generation
carbox validate -p 4LGN --atom "A:75:OD2" --out-restraints 4lgn_restraints.txt

# Launch CarboxMol 3D Crystallographic Studio on a PDB target
carboxmol 4LGN
